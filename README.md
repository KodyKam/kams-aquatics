# Kam's Aquatics – Consultation Planner

A single-page tool for on-site aquarium consultations.

- **Space → tank fit:** enter the available width, depth and height; standard tanks (5.5–125 gal) are marked as fitting or not, with filled-weight warnings.
- **Dirted substrate calculator:** soil and sand amounts (default 1:2 ratio) in litres, cubic feet and bags to buy.
- **Cichlid builds:** egg crate cut size and number of 2' × 4' panels, placed between the soil and sand.
- **Live quote:** supplies, materials markup, flat setup fee by tank size, stand assembly, consultation fee with a booking reward, Uber-based travel per visit, optional HST. Copy the quote as text to send to a client.

No build step or dependencies. Open `index.html` in a browser, or host it with GitHub Pages or Netlify.
